# ربات مدیریت

برای اجرای پنل خصوصی مدیریت، یک ربات جداگانه در BotFather بسازید و مقدارهای زیر را در `.env` تنظیم کنید:

```env
ADMIN_BOT_TOKEN=توکن_ربات_ادمین
ADMIN_IDS=شناسه_عددی_تلگرام_ادمین1,شناسه_عددی_ادمین2
```

سپس فقط فایل اصلی برنامه را اجرا کنید؛ همین فایل ربات ادمین را هم به‌صورت هم‌زمان بالا می‌آورد:

```bash
python -m app.main
```

بعد از هر تغییر مدل دیتابیس، قبل از اجرای ربات migrationها را اجرا کنید:

```bash
.venv/bin/alembic upgrade head
```

`ADMIN_IDS` باید شناسه عددی واقعی اکانت تلگرام شما باشد، نه شناسه ربات. برای پیدا کردن آن می‌توانید از ربات‌هایی مانند `@userinfobot` استفاده کنید. ربات ادمین را جداگانه با `python -m admin.main` اجرا نکنید، چون اجرای هم‌زمان دو polling برای یک توکن باعث خطای `TelegramConflictError` می‌شود.

ربات ادمین امکان جست‌وجوی کاربر، فعال/غیرفعال‌کردن حساب (غیرفعال یعنی بن)، اضافه‌کردن سکه/الماس/موز، ارسال پیام همگانی متنی یا تصویری با کپشن، ساخت سؤال روزانه، ساخت و ارسال سؤال گروهی به گروه‌های فعال، و ساخت/ویرایش/حذف دبیر و سپر را دارد. خرید دبیر و سپر از بوفه انجام می‌شود؛ سپر فعال در اولین حمله‌ی دریافتی درصدی و مقدار ثابتی از آسیب را کم می‌کند و یک واحد مصرف می‌شود. حذف دبیر یا سپری که قبلاً در بازی استفاده شده‌اند به‌صورت امن به غیرفعال‌سازی تبدیل می‌شود تا سابقه بازی و کلیدهای خارجی آسیب نبینند. قواعد کلی فرمول سپر در بخش `[shield_rules]` فایل `config/game_balance.toml` قابل تغییر است.
